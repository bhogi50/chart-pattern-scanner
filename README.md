# Chart Pattern Scanner — PatternPy + TradingView

- Pattern detection is performed only by PatternPy.
- The scanner shows the latest PatternPy detection(s) for each stock.
- Clicking View opens TradingView's free hosted Advanced Chart widget for the selected NSE symbol.
- Daily / Weekly / Monthly selection controls the TradingView interval as well as the PatternPy input data.
- No custom confidence, targets, stop loss, R:R, flag detector, or custom pattern detector is included.

TradingView widget documentation: https://www.tradingview.com/widget-docs/widgets/charts/advanced-chart/
