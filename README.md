# Chart Pattern Scanner V11

Clean pattern-only Streamlit scanner.

Main scan page has no charts. Click View on a detected stock to show target details and an annotated candlestick chart.

Timeframes: Daily, Weekly, Monthly. Universes: NIFTY 50, NIFTY Next 50, NIFTY Midcap 150, NIFTY Smallcap 250.

Patterns include triangles, wedges, channels, flags, double tops/bottoms, H&S, inverse H&S, rectangles, cup & handle, pennants and breakout/breakdown.

No ASTA setup engine or ASTA imports.
